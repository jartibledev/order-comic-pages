# Rename files

This is a standalone executable designed to batch rename any type of file into a sequential numerical order, regardless of their original format. It is ideal for organizing comic pages, manga, or image collections.

### How to Use
1. Go to the directory dist and click on the file .`exe`.
2. Run the application.
3. Select your preferred sorting mode (Sequential, Even, or Odd).
4. Select the folder where you want to change the name of your files.
5. Done! Your files will be renamed instantly.
