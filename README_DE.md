# Dateien umbenennen

Dies ist eine eigenständige ausführbare Datei (*Standalone*), die für die Massenumbenennung von Dateien jeglicher Art in eine fortlaufende numerische Reihenfolge entwickelt wurde – unabhängig von ihrem ursprünglichen Format. Ideal zum Organisieren von Comic-Seiten, Mangas oder Bildersammlungen.

### Anwendung
1. Gehen Sie in das Verzeichnis `dist` und klicken Sie auf die `.exe`-Datei.
2. Führen Sie die Anwendung aus.
3. Wählen Sie den gewünschten Sortiermodus (Fortlaufend, Gerade oder Ungerade).
4. Wählen Sie den Ordner aus, in dem Sie Ihre Dateien umbenennen möchten.
5. Fertig! Ihre Dateien werden sofort umbenannt.

## Installation des Plugins
Sie können dieses Plugin mit dem folgenden Befehl herunterladen:
```bash
git clone https://github.com/jartibledev/order-comic-pages.git
```
oder laden Sie die ZIP-Datei herunter.

## Bekannte Probleme
>[!WARNING]
> Verwenden Sie dieses Plugin nicht in Systemverzeichnissen wie dem Desktop oder dem Benutzerordner (Users). Nutzen Sie es nur in Ordnern, die Sie speziell für Ihre Projekte angelegt haben.
