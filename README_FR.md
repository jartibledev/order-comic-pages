# Renommer les fichiers

Il s'agit d'un exécutable autonome (*standalone*) conçu pour renommer en masse tout type de fichier dans un ordre numérique séquentiel, quel que soit leur format d'origine. Il est idéal pour organiser les pages de bandes dessinées, de mangas ou des collections d'images.

### Comment l'utiliser
1. Allez dans le répertoire `dist` et cliquez sur le fichier `.exe`.
2. Lancez l'application.
3. Sélectionnez le mode de tri souhaité (Séquentiel, Pair ou Impair).
4. Sélectionnez le dossier dans lequel vous souhaitez renommer vos fichiers.
5. Terminé ! Vos fichiers seront renommés instantanément.

## Comment installer le plugin
Vous pouvez télécharger ce plugin avec la commande suivante :
```bash
git clone https://github.com/jartibledev/order-comic-pages.git
```
ou en téléchargeant le fichier ZIP.

## Problèmes connus
>[!WARNING]
> N'utilisez pas ce plugin dans des répertoires système tels que le Bureau ou le dossier Utilisateurs. Utilisez-le uniquement dans des dossiers créés spécifiquement pour vos projets.
